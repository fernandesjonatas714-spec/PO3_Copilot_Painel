# PO3 Copilot V2 — visão do usuário

O PO3 Copilot organiza os dados do MT5, calendário e fontes autorizadas para classificar o contexto do pregão.

- A IA não opera.
- A IA não envia ordens.
- O sistema classifica o contexto em português.
- O Decision Gate pode marcar uma análise como válida, exigir revisão ou bloquear quando os dados forem insuficientes.
- Contexto comprador não significa ordem de compra.
- Contexto vendedor não significa ordem de venda.
- A decisão final continua manual.

A análise diária mantém três partes: macroeconomia e dia a dia, impacto na Bolsa e insight operacional. Quando necessário, o sistema faz uma segunda análise independente e informa consenso ou divergência.
